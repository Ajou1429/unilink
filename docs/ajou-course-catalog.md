# 아주대학교 2026년 2학기 과목 편성

시간표 상단의 **아주대 과목 찾기**에서 과목명·교수·수강번호·교과목코드를 검색한다.
학과, 이수구분, 영어강의, 공강 희망 요일로 필터링하고 분반을 담은 뒤 미리보기에서 확인한다.
선택한 강좌만 2026년 2학기 시간표에 추가한다. 다른 학기와 기존 수업은 보존한다.

## 자료와 제한

- 제공받은 `2026-2학기_과목개설_현황(26.09.02(수)_현재).xls`의 2026-09-02 스냅샷이다.
- 수강번호 기준 1,820개 강좌, 강의시간이 있는 1,421개, 시간 미기재 399개.
- 원본 행의 수강번호, 과목 ID, 교과목코드, 학점, 담당 교수, 이수구분, 대상 학년,
  영어강의·유학생 전용·우선수강 여부, 수업방식과 시간 문자열을 보존한다.
- 학교 수강신청이나 실시간 잔여석 조회가 아니다. 개인 수강 자격도 자동 판정하지 않는다.
- 시간 미기재·해석 불가 강좌는 목록에 남기되 자동 배치를 막는다. 원본 확인 후 직접 추가한다.
- 저장은 프로젝트의 기존 브라우저 localStorage를 사용한다. 계정별 서버 동기화는 별도 작업이다.
- 공강 필터는 검색 대상 강좌에 적용한다. 이미 편성한 일정이 그 요일에 있으면 안내한다.

## 시간 변환

[아주대학교 교시별 강의시간 안내](https://www.ajou.ac.kr/gs/bachelor/enrolment.do)를 기준으로
A~H는 09:00부터 90분 간격, 수업 길이는 75분이다. 숫자 교시는 1교시 09:00부터
60분 간격, 수업 길이는 50분이다. 소수 `.5`는 시작을 30분 늦춘 것으로 해석한다.
[2026-2 미래모빌리티공학과 안내](https://www.ajou.ac.kr/mobility/board/notice.do?articleNo=372169&mode=view)의
2.5교시 10:30 시작 표기도 참고했다. 종료는 일반 50분 교시 규칙을 적용하며,
원본에 실제 시각 범위가 명시되면 그 범위를 우선한다. 원본 시간도 검색 결과에 함께 표시한다.
같은 요일·강의실의 연속 교시는 10분 휴식까지 묶어 표시하고, 강의실이 달라지면 분리한다.

동일 과목의 다른 분반은 중복 편성을 막으며, 수업·기타 일정과 겹치는 강좌는 선택할 수 없다.
저장 직전 최신 저장소로 다시 검증한 후 한 번에 저장한다. 수업 시간 수정 시에도 수강번호 등 출처를 보존한다.

## 데이터 갱신 및 검증

엑셀 처리는 빌드·브라우저 실행에 필요하지 않다. 개발자가 자료를 갱신할 때만 Python과 xlrd가 필요하다.

```powershell
python -m pip install xlrd
python scripts/import-ajou-catalog.py '원본파일.xls'
node --experimental-strip-types --test tests/ajou-catalog.test.mjs
npm run build
```

변환 파일은 `src/data/ajou-2026-2.json`이다. 원본 SHA-256과 기준일을 포함한다.
다른 학기·기준일의 파일을 반영할 때는 변환기의 학기·기준일과 UI 상수, 테스트 기준을 함께 갱신한다.
