# 공개 데모 AI 운영

- 진입: `/dashboard?demo=1`. `demo-chat`은 로그인 없는 데모 전용 함수다. 운영 계정 조회나 계정 데이터 변경 경로를 호출하지 않는다. 승인된 일정·계획·목표·분류·완료는 기존 demo sessionStorage에만 저장한다.
- 실제 AI: 자연어 학습 대화, 계획 추천, 일정 등록, 화면 이동, 샘플 노트 분류, 계획 완료, 개인 목표 제안. 변경은 확인 카드의 승인 또는 `예` 이후 반영한다. 거절은 저장하지 않는다. PDF 업로드/분석은 여전히 명시된 샘플 체험이며 실제 파일 분석이라고 표시하지 않는다. Drive 체험은 제거했다.
- 대화·샘플 학습 정보는 OpenAI Responses API에 `store:false`로 전달한다. API 키는 Edge 시크릿에만 존재한다. 입력에 개인정보를 넣지 않도록 화면에 안내한다. 대화 원문을 서버 DB나 로그에 저장하지 않는다.
- 한도: 한국시간 날짜별 동일 네트워크의 계획 결과 생성 3회, 대화 시도 60회. 여러 방문자가 같은 네트워크이면 한도를 공유한다. 계정별 식별 한도가 아니다. IP는 원문 저장 없이 서비스 키 기반 HMAC으로 사용량 테이블에서 식별한다. 게이트웨이의 `x-forwarded-for`가 없으면 실패한다. 프록시 헤더 신뢰 및 네트워크 변경의 한계가 있으므로 엄격한 사람별 한도가 필요하면 로그인·CAPTCHA를 추가해야 한다.
- 비용 상한: 서버의 전역 예산도 한국시간 날짜별 대화 1,000회/계획 100회를 적용한다. 한도 테이블/RPC는 service_role만 접근하며 advisory lock으로 동시 차감을 직렬화한다. 계획 결과 검증에 성공한 후 예약하고, 네 번째 결과는 클라이언트에 반환하지 않는다. 생성 한도 소진 시 모델에 새 계획 생성을 금지하며 일반 대화는 유지한다. 실패한 대화 시도도 대화 한도를 소비하며, 실패/거절 결과는 계획 횟수에 포함하지 않는다.
- 초기화: ‘처음부터 체험’과 새로고침은 서버 한도를 초기화하지 않는다. 익일 한국시간 자정 이후 새 날짜 한도를 사용한다.
- 설정: `PUBLIC_DEMO_AI_ENABLED=true`; 선택적으로 `DEMO_CHAT_MODEL`, 기본은 기존 `CHAT_ASSISTANT_MODEL` 또는 `gpt-6.1-terra`. 기존 `OPENAI_API_KEY` 사용.
- DB: `0046_public_demo_quota.sql`은 전용 테이블과 제한 RPC만 추가한다. 운영 학습 테이블을 변경하거나 삭제하지 않는다.
- 중단/복구: `PUBLIC_DEMO_AI_ENABLED=false`로 새 공개 AI 호출을 차단할 수 있다. 데이터를 보존한 채 함수/웹을 이전 버전으로 복귀할 수 있으며 운영 테이블 롤백은 필요 없다.
- 검사: `tests/demo-chat.test.mjs`의 날짜/액션/권한/동시 4회·익일 한도 검사, `tests/public-demo.browser.mjs`의 실제 API 계약 모의응답/승인/한도/리셋/PC·모바일/계정 분리 검사. 브라우저 회귀는 유료 API를 호출하지 않는다.
