# 시간표 수정 사항 (2026-11-12)

시간표 화면에서 세 가지를 고쳤습니다. 다른 화면은 시간 미정 과목 표시 문구만 바뀌었습니다.

## 1. 시간 미정·별도 운영 과목도 시간표에 추가

**이전:** 강의시간이 비어 있는 강좌(카탈로그 1,820개 중 399개)는 "시간 미정·별도 운영" 사유로 `담기` 버튼이 막혀 있었습니다.

**변경:**
- 수업 추가 창에서 이런 강좌도 담을 수 있습니다. 카드에 "시간표 하단 목록에 표시됩니다" 안내가 나옵니다.
- 주간 시간표 격자 **아래에 과목 이름 목록**으로 표시됩니다(색상 점 · 과목명 · `시간 미정·별도 운영 · N학점`). 누르면 오른쪽에 과목 상세가 열립니다.
- 시간이 없으므로 시간 겹침 검사에서 제외되고, 총 학점에는 포함됩니다.
- 수업 추가 창의 미리보기에도 격자 아래에 같은 목록이 나옵니다.
- 수강 목록, 과목 상세, 수업 페이지, 기록 페이지에서 요일 대신 `시간 미정·별도 운영`으로 표시됩니다.
- 과목 수정에서 요일을 모두 해제하면 시간 미정 과목으로 저장됩니다(이전에는 저장이 막혔습니다). 시간 미정 과목에 요일을 지정하면 시간이 비어 있을 때 09:00–10:00이 기본값으로 들어갑니다.
- 공강 요일 필터를 켜면 시간 미정 강좌는 검색 결과에서 빠집니다(요일을 보장할 수 없음).

**데이터:** `Course` 타입은 바뀌지 않았습니다. 시간 미정 과목은 `schedules: []`, `days: []`, `startTime/endTime: ""`로 저장됩니다. DB 동기화(`p0-sync`)는 `courses` 행만 만들고 `course_schedules` 행은 만들지 않습니다(기존 로직 그대로 동작).

## 2. 최대 수강 학점 직접 설정

**이전:** 총 학점 카드의 "N학점 여유"가 18학점 고정 기준이었습니다.

**변경:**
- 총 학점 카드 아래에 **최대 수강 학점** 선택 메뉴를 추가했습니다(9–24학점, 기본값 18).
- 배지 문구: 남으면 `N학점 여유`, 같으면 `최대 학점`, 넘으면 `N학점 초과`(빨간색).
- 설정값은 사용자별 로컬 저장소(`unilink:max-credits`, `privateStorage`)에 저장됩니다. 아직 DB에는 동기화하지 않습니다.

## 3. 월간 일정 탭의 이동 버튼

**이전:** 월간 일정 탭으로 바꿔도 오른쪽 위에 주간 이동(◀ 주 범위 ▶)이 남아 있었고, 월 이동은 달력 카드 안에 따로 있었습니다.

**변경:**
- 탭 상태에 따라 오른쪽 위 이동 도구가 바뀝니다. 주간 시간표에서는 `◀ 주 범위 ▶`, 월간 일정에서는 `◀ 2026년 N월 ▶`입니다.
- 달력 카드 안에 있던 월 이동 버튼과 월 선택 드롭다운은 없앴습니다(제목과 안내 문구만 남김).
- 월 범위는 기존처럼 2026년 1–12월이며, 끝에 닿으면 버튼이 비활성화됩니다.
