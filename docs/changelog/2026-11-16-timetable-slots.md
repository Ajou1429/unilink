# 시간표 직접 추가 시간·하루 여러 번 수업, `채팅하기` (2026-11-16)

## 1. 직접 추가의 시간 선택

- 시간표 `직접 추가`의 시간 목록을 **오전 9시 ~ 오후 9시, 15분 단위**로 바꿨습니다(09:00, 09:15 … 21:00, 49개).
- 칸에 시간을 직접 입력해도 이 범위의 가장 가까운 15분 단위로 맞춰집니다(예: 17:20 → 17:15, 07:00 → 09:00).
- 일정 추가·과목 정보 수정 등 다른 시간 칸은 그대로입니다(하루 전체, 30분 단위). `TimeField`에 `options`를 넘길 때만 범위가 바뀝니다.

## 2. 하루에 두 번 이상 하는 수업

- 요일을 고르면 시간 칸이 하나 생기고, 그 요일 줄 끝의 `+`로 **같은 요일에 시간을 더 추가**합니다(예: 수 10:00, 금 10:00, 금 16:00).
  - 새 칸은 그 요일 마지막 수업 15분 뒤에 같은 길이로 들어갑니다. 오후 9시를 넘지 않습니다.
  - `×`로 시간 하나만 뺄 수 있습니다. 요일 버튼을 다시 누르면 그 요일 시간이 모두 빠집니다.
- 같은 과목의 같은 요일 시간끼리 겹치면 저장하지 않고 알려 줍니다. 다른 과목·일정과 겹치는지도 지금처럼 확인합니다.
- 저장은 기존 `schedules` 배열을 그대로 씁니다(같은 요일이 여러 번 들어감). 시간표 칸, 과목 정보 수정, DB 동기화는 원래 시간별로 따로 다뤄서 바꾸지 않았습니다.
