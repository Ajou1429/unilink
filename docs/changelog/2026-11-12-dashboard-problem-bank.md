# 대시보드 개편 · 검색창 제거 · 문제은행 기능 main 반영 (2026-11-12)

## 1. 대시보드: 시험·과제 박스

- 위 줄에 박스 3개가 놓입니다.
  - 기존 `이번 주 학습 계획` 박스를 없앴습니다.
  - 그 자리에 **`시험·과제`** 박스가 들어갑니다.
  - 순서는 `오늘 계획 | 시험·과제 | 오늘 수업`입니다.
- 아래에 따로 있던 `예정 일정`(시험/과제 두 칸) 카드는 없앴습니다. 세 박스가 화면 아래까지 늘어납니다.
- 시험과 과제는 한 목록으로 합쳐 **날짜가 가까운 순**으로 정렬합니다.
- 왼쪽에 D-day 배지를 붙였습니다(한국 날짜 기준).
  - `D-Day`, `D-1`, 지난 과제(`D+n`): 빨강
  - `D-2`: 주황
  - `D-3` 이상: 초록
- 각 행에는 제목과 `시험/과제 · 과목 · 날짜`가 나옵니다. 누르면 해당 수업 페이지로 이동합니다.
- 데이터는 이전과 같습니다.
  - DB `calendar_events`에서 `event_type`이 `exam`(앞으로 남은 것)과 `assignment`(미완료, 기한 지난 것 포함)인 일정을 가져옵니다. 종류별 최대 8개입니다.
  - 로그인해야 보입니다.
- 파일: `src/components/dashboard/ExamAssignments.tsx`, `src/app/(dashboard)/dashboard/page.tsx`

## 2. 대시보드: 오늘 계획에 날짜 이동과 미루기

- 오늘 계획 박스 오른쪽 위에 `◀ 11월 12일 (목) ▶`를 추가했습니다.
  - 날짜를 누르면 오늘로 돌아옵니다.
  - 오늘이 아닌 날을 보고 있으면 제목이 `계획`으로 바뀝니다.
- 페이지 오른쪽 위에 있던 파란 날짜 배지는 없앴습니다.
- 계획마다 **`미루기`** 버튼이 있습니다. 누르면 다음 날로 옮기고 `n회 미룸`(주황)을 표시합니다.
  - **직접 만든 학습 계획**(로컬 `StudyPlan`)
    - `dueDate`를 하루 뒤로 옮기고 `postponedCount`를 1 올립니다.
    - `weekStart`가 있으면 새 날짜가 속한 주(일요일 시작)로 맞춥니다.
    - p0 동기화로 DB `study_plans`/`study_plan_items`에 반영됩니다. 기록은 `legacy_record`에 남습니다.
  - **AI 계획 항목**(DB `study_plan_items`)
    - `scheduled_start`/`scheduled_end`를 24시간 뒤로 옮깁니다.
    - `metadata.postpone_count`를 1 올립니다.
    - 본인 행 수정이라 기존 RLS로 허용됩니다. 코칭 상태 revision도 기존 트리거로 올라갑니다.
- 파일: `src/components/dashboard/TodayPlans.tsx`, `src/lib/study-storage.ts`(`postponeWeeklyStudyPlan`), `src/lib/types.ts`(`postponedCount`)

## 4. 문제은행 새 기능 main 반영

- `problembanknewversion` 브랜치의 `dc061a9`(브라우저에서 PDF 문제 번호 추출, 확인 후 업로드)를 main에 병합했습니다. 충돌은 없었습니다.
- **마이그레이션 번호 변경:** 브랜치의 `0028_problem_bank_files.sql`을 **`0033_problem_bank_files.sql`**로 바꿨습니다. main에 이미 `0028`~`0032`가 있기 때문입니다. 마이그레이션 테스트도 0032 다음에 적용하도록 고쳤습니다.
- ⚠️ **운영 DB에는 아직 0033을 적용하지 않았습니다.**
  - 적용 전에도 문제은행 화면은 동작합니다.
  - 다만 같은 과목에서 **다른 PDF에 같은 문제 번호**(예: 과제1의 1번, 과제2의 1번)를 저장하면, 기존 unique(subject_id, label) 제약 때문에 실패합니다.
  - 운영 적용이 필요합니다.
