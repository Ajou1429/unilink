# 문제은행 문제 내용 보기 (2026-11-13, `feature/chat-record` 브랜치 · main 미반영)

이전에는 문제은행에 문항 번호만 저장했습니다. 문제를 보려면 원본 PDF를 따로 열어야 했습니다.
이제 **번호를 누르면 그 아래에 문제가 펼쳐집니다.** 같은 화면에서 문제를 보며 이해도를 바로 고를 수 있습니다.

## 화면

- 번호를 누르면 문제가 펼쳐지고, 다시 누르면 접힙니다. 번호 수정은 옆의 연필 버튼으로 합니다(이전에는 번호를 누르면 수정).
- 문제를 정확히 글로 옮겼으면 **글로** 보여 줍니다. 수식(분수·루트·제곱·적분·극한·첨자 등)은 KaTeX로 그립니다.
- 그림·회로·표가 있으면 **그 부분만 그림으로** 크롭해 함께 보여 줍니다.
- 글로 정확히 옮기지 못했으면(스캔 문제, 표 등) **문제 영역 전체를 그림으로** 보여 줍니다.
- 크롭 그림은 페이지를 약 2200px 폭(A4 기준 약 270dpi)으로 그려 자른 뒤 화면에서는 절반 크기로 보여 줍니다. 그래서 고해상도 화면에서도 선명합니다. 흰 여백은 자동으로 걷어 냅니다.
- 규칙과 AI가 찾은 번호가 다르면 번호 옆에 주황 점이 붙습니다.
  - 파일 줄에는 `확인 필요 N`이 표시됩니다.
  - 펼치면 `번호 맞음` / `삭제` 버튼이 있습니다.
- 강의노트에서 찾은 문제는 파일 이름 앞에 `강의노트` 표시가 붙습니다.
- 이해도는 지금처럼 0~5를 누르거나, 홈 채팅에서 말하면("수학 중간 기출 5번 모르겠어") 반영됩니다.

## 분석 순서 (브라우저 → `problem-analyze` 서버 함수)

1. PDF 페이지마다 글자 레이어가 있는지 봅니다(글자 PDF / 스캔·이미지 PDF).
2. 글자 PDF는 기존 규칙으로 문항 번호와 위치를 찾습니다.
3. AI 분석에 동의한 로그인 계정이면, 페이지 그림(1400px JPEG)과 글자 줄(위치 포함)을 페이지별로 AI(OpenAI)에 보냅니다.
   - 받아 오는 것: 문항 번호(인쇄된 그대로), 소문항, 문제 영역, 본문(LaTeX 수식), 그림 영역, 다음 페이지로 이어지는지
   - 페이지 그림은 저장하지 않습니다.
4. **번호 이중 확인**: 규칙과 AI가 같이 찾은 번호는 확인됨, 한쪽만 찾은 번호는 `확인 필요`입니다. 스캔 PDF는 AI만 읽으므로 모두 `확인 필요`입니다.
5. 필요한 영역을 고해상도로 그려 크롭하고, 문항 번호와 함께 저장합니다.

- 같은 파일을 다시 올리면 기존 번호·이해도는 그대로 두고 **문제 내용만 채웁니다**. 그래서 이전에 번호만 올린 파일도 다시 올리면 됩니다.
- AI 동의 전이거나 비로그인·데모이면 지금처럼 규칙으로 찾은 번호 목록을 확인받아 저장합니다. 이때는 문제 영역 그림만 붙습니다.
- 한도:
  - 문제 파일은 앞 60페이지까지 AI로 봅니다. 나머지 페이지 번호는 규칙 결과로 `확인 필요`가 됩니다.
  - 하루 400페이지까지입니다.
  - 한도에 걸리면 남은 페이지는 규칙 결과만 남깁니다.

## 강의노트 안의 문제

- 대시보드에서 올린 파일이 `강의자료`로 분류된 PDF이고 AI 분석에 동의했으면, 문제가 있을 만한 페이지만 AI로 봅니다.
  - 대상 페이지: 문제·예제·연습·Quiz·Exercise·Q. 표시가 있는 페이지, 글자 레이어가 없는 스캔 페이지
  - 최대 25페이지
- 찾은 문제는 그 과목의 문제은행에 `강의노트 파일명` 아래로 들어갑니다. 이름은 `p.12`이고, 한 페이지에 여러 문제가 있으면 `p.12-1`, `p.12-2`입니다.
- PPTX는 슬라이드를 그림으로 그릴 수 없어 제외했습니다(PDF로 저장해 올리면 됩니다).

## 저장

- 마이그레이션 `0036_problem_content.sql`
  - `problem_bank_problems.content jsonb`를 추가했습니다. 내용은 본문, 그림 경로, 페이지, 확인 필요 여부, 출처(both/rule/ai), 종류(problem/lecture)이고 64KB 상한입니다.
  - AI 한도에 `problem` 종류를 추가했습니다(24시간 400회). 파일 분류·대화 한도와 따로 셉니다.
- 크롭 그림
  - 로그인: 기존 `note-files` 저장소의 `<사용자>/problem-bank/…webp`에 넣습니다. 기존 저장소 권한 규칙 그대로입니다.
  - 비로그인·데모: 브라우저 IndexedDB에 넣습니다.
  - 문항·파일을 지우면 그림도 지웁니다.
- 동의는 문제은행 탭에서 처음 PDF를 넣을 때 한 번 받습니다(`unilink:problem-analysis-consent`). 파일 분류·대화 동의와 따로 받습니다. `번호만 찾기`를 고르면 AI 없이 동작합니다.
- 새 패키지: `katex@0.16.22`
