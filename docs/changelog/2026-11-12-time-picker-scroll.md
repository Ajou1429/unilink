# 시간 선택 스크롤 감도 조정 (2026-11-12)

## 무엇이 바뀌었나

- 시간 입력칸 오른쪽의 시간 선택 목록을 브라우저 기본 `<select>`에서 **직접 만든 목록**으로 바꿨습니다. 사용하는 곳은 일정 추가·수정, 시간표의 과목 수정입니다.
- 기본 `<select>`는 마우스 휠 한 칸에 여러 줄(약 3줄)이 넘어가고, 웹에서 그 속도를 조절할 수 없었습니다.
- 새 목록의 스크롤 규칙
  - **마우스 휠 한 칸 = 정확히 한 줄(30분)** 이동합니다.
  - 트랙패드처럼 작게 여러 번 들어오는 스크롤은 모아서 한 줄씩 움직입니다(기준 `WHEEL_STEP = 60`).
  - 목록 위에서 휠을 굴려도 뒤의 팝업 창은 함께 스크롤되지 않습니다.
- 목록을 열면 지금 값이 위에서 셋째 줄쯤 보이게 열립니다. 한 번에 6줄이 보입니다.
- 키보드: ↑/↓로 이동, Enter로 선택, Esc는 목록만 닫습니다(팝업 창은 유지). 바깥을 누르면 닫힙니다.
- 버튼은 잘리던 `오전 …` 글자 대신 시계 아이콘으로 바꿨습니다. 시간은 왼쪽 입력칸에 이미 표시됩니다. 입력칸에 직접 입력하는 기능은 그대로입니다.
- 대시보드 시험·과제 추가 창의 날짜·시간 입력은 브라우저 기본 날짜 선택기를 쓰고 있어서 이번 변경과 관계없습니다.
