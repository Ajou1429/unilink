# 대시보드 빠른 추가 · 문제은행 과목 자동 연동 · 사이드바 정리 (2026-11-12)

## 1. 대시보드에서 바로 추가

- **오늘 계획 `+`**
  - 할 일, 과목(기본값 `개인 학습`), 날짜(기본값은 지금 보고 있는 날)를 넣어 학습 계획을 추가합니다.
  - 학습 계획 페이지와 같은 저장소를 씁니다. 주간 계획(`unilink:weekly-study-plans`)에 들어가고, 월간 보기에도 함께 반영됩니다. p0 동기화로 DB에도 올라갑니다.
  - 헬퍼: `addWeeklyStudyPlan` (`src/lib/study-storage.ts`)
- **시험·과제 `+`**
  - 과제 또는 시험을 고르고 과목(필수), 제목, 날짜를 넣습니다.
    - 과제: 마감
    - 시험: 시작과 종료 시각, 시험 범위
  - **과목 페이지의 과제·시험과 같은 데이터**입니다. 그 과목의 학습 목표에 연결된 `calendar_events` 행으로 저장되므로, 과목 페이지 목록과 AI 코칭에 그대로 반영됩니다. 출처는 `metadata.source = "dashboard-quick-add"`로 남깁니다.
  - 로그인해야 사용할 수 있습니다. 시간표에 과목이 없으면 버튼이 비활성화됩니다.
  - 헬퍼: `createCourseEvent`, `findCourseGoalId` (`src/lib/course-events.ts`). 추가 후 `unilink:courseEventsChanged` 이벤트로 목록을 다시 읽습니다.
- 과목 선택지는 현재 학기 시간표 과목입니다. 방학 중이면 직전 학기 과목입니다(아래 4번).

## 2. 문제은행

- 제목을 `문제 이해도 원장`에서 **`문제은행`**으로 바꿨습니다.
- 제목 위의 `MASTERY LEDGER`와 아래의 회색 설명을 없앴습니다. 빈 화면의 회색 보조 문구도 없앴습니다.
- **과목 자동 연동**
  - 문제은행에 들어오면 현재 학기 시간표 과목마다 문제은행 과목이 자동으로 만들어집니다.
  - 이름이 같은 기존 과목이 연결 없이 있으면, 새로 만들지 않고 그 과목을 씁니다.
- **과목 삭제**
  - 과목 탭 오른쪽의 `과목 삭제`로 지웁니다. 문항과 이해도 기록도 함께 지워집니다.
  - 자동 연동으로 생긴 과목을 지우면 다시 만들지 않습니다. 이 기록은 브라우저별로 저장됩니다(`unilink:problem-bank-dismissed-courses`).
- **중간고사 범위 / 기말고사 범위 탭**
  - 과목마다 두 탭이 있습니다. 파일 업로드, 직접 입력, 통계는 지금 고른 탭 기준입니다.
  - 저장 방식: DB 컬럼을 추가하지 않고 `source_file` 앞에 `final::` 또는 `midterm::`를 붙여 저장합니다(`splitSourceFile`, `joinSourceFile` in `src/lib/problem-bank-labels.ts`).
    - 접두사가 없는 기존 파일은 중간고사 범위로 봅니다.
    - 이렇게 하면 아직 운영에 적용하지 않은 0033 외에 새 마이그레이션이 필요 없습니다.
    - 파일 이름은 최대 180자로 줄였습니다(접두사 포함 200자 제한).
- **코칭 연결 선택 UI 삭제**
  - `코칭 학습 목표` / `이 문제은행 전체의 공통 주제` 선택 영역(`ProblemBankCoachingLink`)을 없앴습니다.
  - 대신 자동 연동할 때 `problem_bank_coaching_links`에 그 과목의 학습 목표를 연결합니다(`topic_id`는 비움). 그래서 문항 이해도가 별도 선택 없이 AI 코칭 근거(`coaching_problem_bank_states`)에 들어갑니다.
  - 직접 만든 과목(시간표에 없는 과목)은 연결되지 않아 코칭에 들어가지 않습니다.
- 파일: `src/app/(dashboard)/problem-bank/page.tsx`, `src/lib/problem-bank-storage.ts`(`syncSubjectsWithCourses`, `deleteSubject`)

## 3. 대시보드 인사말

- 이름 아래의 `2026년 2학기 · 로그인 후 회원 정보의 학과가 표시됩니다` 회색 줄을 없앴습니다.
- `안녕하세요, 누구님` 대신 **한국 시간 기준 시간대별 인사말**을 보여줍니다. 시간대마다 2~3개 문구가 있고 날짜마다 돌아가며 나옵니다.

  | 시간 | 예시 |
  | --- | --- |
  | 0~5시 | 새벽까지 공부 중이시군요 |
  | 5~9시 | 좋은 아침이에요 |
  | 9~12시 | 좋은 오전이에요 |
  | 12~14시 | 점심은 챙겨 드셨나요? |
  | 14~18시 | 오후도 힘내요 |
  | 18~22시 | 오늘 하루도 수고 많았어요 |
  | 22~24시 | 늦은 저녁에도 열심히 하시는군요 |

- 파일: `src/lib/greeting.ts`

## 4. 사이드바 `내 수업` / `개인 학습`

- 두 섹션을 **눌러서 펼치는 드롭다운**으로 바꿨습니다. 기본은 접힘이고, 해당 페이지(수업·개인 학습)에 있을 때는 펼친 상태로 시작합니다.
- `내 수업`은 원래 현재 학기(`getCurrentAcademicTermLabel`)의 시간표 과목만 보여줬습니다. 그래서 학기가 바뀌면 자동으로 바뀌고, 과목이 누적되지는 않았습니다.
- 다만 방학(여름학기 7~8월, 겨울학기 12월 이후~2월)에 계절학기 수업이 없으면 목록이 비는 문제가 있었습니다. 이제는 **현재 학기에 수업이 없으면 직전 학기 수업**을 보여줍니다(`getActiveTermCourses` in `src/lib/course-storage.ts`). 문제은행 자동 연동과 대시보드 과목 선택도 같은 기준을 씁니다.
