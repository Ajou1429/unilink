# 채팅 파일 저장 전 확인 · 강의계획서 분류 · 원본 바로 열기 (2026-11-17)

## 1. 채팅에 올린 파일은 확인한 뒤 저장

- 이전에는 채팅에 파일을 올리면 분류와 동시에 과목·노트·문제은행·시간표에 바로 저장했습니다.
- 이제 **분류까지만** 하고 저장 전 상태(주황 점선 표시)로 둡니다. 결과 카드의 종류·과목 선택칸으로 고칠 수 있고, 고쳐도 저장되지 않습니다.
- 저장은 두 가지 방법으로 합니다.
  - **채팅(GPT)**
    - 분류가 끝나면 GPT가 결과를 자기 말로 알려 주고 저장해도 될지 묻습니다.
    - 학생의 답을 GPT가 해석합니다: 저장 / 특정 파일의 종류·과목 수정 / 저장하지 않기
    - 질문·답 문장은 코드에 정해 두지 않았습니다. 코드는 GPT에게 판단 기준과 저장 대기 파일 목록만 주고, 문장은 GPT가 씁니다.
  - **카드의 `저장` 버튼**: GPT를 쓸 수 없을 때(비로그인·데모·`chat-record` 배포 전)도 저장할 수 있습니다.
- GPT 연결 방식(`chat-record`)
  - 요청: `event`(`message` / `files_ready`), `pending_files`(f1, f2… 파일명·종류·과목·새 과목명)
  - 응답: `file_actions`(`save` / `set` / `discard`)
  - 서버에서 다시 검사합니다: 모르는 파일·과목·종류·동작은 버리고, 분류 결과를 알리는 `files_ready` 호출에서는 아무것도 저장하지 않습니다.
- 강의계획서는 분류 단계에서 항목까지 읽습니다. 카드에 기존 과목 또는 `새 과목: 과목명`을 보여 주고, 시간표 추가·성적 반영비율 저장은 확인 후에 합니다.
- Drive에서 자동으로 들어온 노트 분류는 이전처럼 바로 반영합니다(이미 UniLink에 있는 노트라서).

## 2. 지금 학기 과목으로만 분류

- 자동 분류의 과목 후보와 카드의 과목 선택지를 **지금 진행 중인 학기**(방학 중엔 직전 학기) 과목으로만 바꿨습니다. 지난 학기 과목으로 잘못 들어가던 문제를 막습니다.
- 강의계획서에 적힌 학기의 과목을 찾는 것(이미 있으면 합치기)은 그대로입니다.

## 3. 강의계획서 분류 (실제 계획서 4개로 맞춤)

- 사용자가 보낸 아주대 포털 강의계획서 4개(자료구조및알고리즘이해, 신호 및 시스템, 전자장론, 전자회로1)를 기준으로 고쳤습니다.
- 잘못 분류되던 이유:
  - 본문에 `강의계획서`라는 말이 없습니다. `수업계획서`는 6쪽 AI 정책 안내에만 나옵니다.
  - 진도 계획(1~16주, `과제1`, `practice #1`, `중간고사`)과 성적 표가 강의자료·문제은행 규칙에 먼저 걸렸습니다.
- `syllabusScore`(브라우저) 점수: 아래 특징을 함께 봅니다. 7점 이상이면 AI 없이 강의계획서로 확정합니다.
  - 아주대 양식 항목 이름: `학수구분`, `교과목코드`, `개설년도/학기`, `강의시간 및 강의실`, `학습평가 방법`, `평가비율`, `진도 계획`, `생성형 AI 활용 정책` 등
  - % 없는 성적 표 행(`중간고사 1 30`)
  - 주차 번호, 수업 목표·교재·담당교수 같은 일반 항목
- AI가 강의자료·문제은행이라고 해도 강의계획서 점수가 5 이상이면 강의계획서로 봅니다. AI 분류 지시문에도 강의계획서의 특징(성적 비율 표, 주차별 계획)을 적었습니다.
- **아주대 양식은 AI 없이 항목을 읽습니다**(`parseAjouSyllabus`).
  - 과목명(`담당교수` 바로 위 줄), 교과목코드, 담당교수, 이수구분·학점, 개설 학기
  - 강의시간(`월B(원340) 목B` → 기존 아주대 교시 해석으로 월·목 10:30–11:45)
  - 성적 반영비율: `0~5%`처럼 범위면 큰 값, `출석 0 0`처럼 0이면 뺌
  - 과목명을 못 찾으면 AI로 읽습니다.

## 4. 과목 화면: 이름을 누르면 원본 파일이 새 탭에서 열림

- 강의자료의 `열기` 버튼과 팝업 보기 창을 없앴습니다. **자료 이름을 누르면 원본 파일(PDF 등)이 브라우저 새 탭에서 바로 열립니다.**
  - 원본 위치: 이 브라우저 / 로그인 저장소(서명 주소) / Google Drive
  - 원본이 없는 자료는 이름이 그냥 글자로 보입니다.
- 문제 칸
  - 파일 이름을 누르면 그 문제를 만든 원본 PDF가 새 탭에서 열립니다. 원본 찾기 순서는 자동 분류 기록, 같은 이름의 강의자료입니다.
  - 원본이 없으면(예전 문제은행 탭 업로드) 문항 목록을 펼칩니다. 왼쪽 화살표는 언제나 문항 목록을 펼칩니다.
- `tests/course-pdf.browser.mjs`를 새 동작 기준으로 고쳤습니다. 새 탭이 실제 PDF(`application/pdf`, `%PDF-`)를 받는지 확인합니다.
