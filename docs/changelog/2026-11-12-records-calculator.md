- 파일: `src/app/(dashboard)/timetable/page.tsx`

## 2. 성적 및 스펙 페이지 (`/records`)

성적 부분을 새로 만들었고, 데스크톱에서 스크롤 없이 한 화면에 들어가게 했습니다.

- **왼쪽: 나의 학점**
  - 전체 평점을 보여줍니다. 재수강 예정 과목이 있으면 아래에 `재수강 시 x.xx / 4.5`를 표시합니다.
  - 전공 평점을 보여줍니다.
  - 취득 학점 `N / 졸업 필요 학점`과 진행 막대를 보여줍니다.
  - **학점계산기** 버튼이 있습니다.
- **오른쪽: 스펙**
  - `스펙 추가` 버튼을 누르면 팝업이 열립니다.
  - 카드마다 종류 배지, 제목, 요약이 나오고 수정·삭제할 수 있습니다.
  - 목록이 길면 카드 안에서만 스크롤됩니다.
- 스펙 종류별 입력 항목은 아래와 같습니다.

  | 종류 | 입력 항목 |
  | --- | --- |
  | 자격증 | 자격증명, 취득연월, 만기연월 또는 `평생 자격증`, 발급기관 |
  | 어학 | 자격증명, 취득연월, 만기연월, 점수 |
  | 공모전 | 공모전명, 주최기관, 수상 이력(자유 입력: 등수·상 이름·상금) |
  | 기타 | 제목, 내용 |

- 기존에 있던 학기별 성적 표, 스펙 진행 상태(예정/진행/완료), 개인 학습 연결 선택 UI는 없앴습니다.
  - 시간표와 개인 학습 페이지에서 학습을 완료하면 스펙으로 자동 등록되는 기능은 그대로 둡니다.
  - 자동 등록 시 종류는 이름으로 판정합니다(자격증·어학·공모전·기타).
- 파일: `src/app/(dashboard)/records/page.tsx`, `src/components/records/SpecDialog.tsx`

## 3. 학점계산기 (`/records/calculator`, 사이드바에는 없음)

- 맨 위에서 학기를 고릅니다(`1학년 1학기` ~ `4학년 2학기`). 이전 형식(`2026년 1학기` 등)으로 저장된 성적은 9번째 칸부터 그 이름 그대로 표시됩니다.
- 요약 칸은 세 개입니다.
  - **전체 평점**: 재수강 예정이 있으면 `재수강 시 x.xx / 4.5`를 함께 보여줍니다.
  - **전공 평점**: 전체 평점과 같은 방식입니다.
  - **취득 학점**: `N / 150`에서 150 부분을 눌러 직접 고칠 수 있습니다. 기본값은 150이고 `unilink:grade-settings`에 저장됩니다.
- 그래프
  - **꺾은선 그래프**: 학기별 전체·전공 평점입니다(0~4.5). 마우스를 올리면 학기별 값이 보입니다.
  - **학점 비율**: 성적 등급별 비율입니다(학점 가중).
- **학점 입력**
  - `시간표 불러오기`: 불러올 시간표를 고릅니다(기본은 현재 학기). 그 시간표의 과목·학점·전공 여부를 지금 고른 학기 칸에 추가합니다. 이미 불러온 과목은 건너뜁니다.
  - `과목 추가`: 직접 입력할 행을 추가합니다.
  - 행마다 과목명, 학점, 성적(A+ ~ F, P, NP), 전공 여부, **재수강 예정**(체크하면 예상 성적을 고를 수 있음)을 입력하고 삭제할 수 있습니다. 바뀐 내용은 바로 저장됩니다.
- 계산 규칙(`src/lib/record-storage.ts`의 `summarizeGrades`)
  - 평점은 학점 가중 평균입니다. P/NP는 평점에서 빠집니다.
  - 취득 학점에서는 F·NP·미입력을 뺍니다.
  - 재수강 예상 평점은 재수강 예정이고 예상 성적이 있는 과목만, 현재 성적 대신 예상 성적으로 계산합니다.
  - 학교별 재수강 상한(A0 제한 등)은 반영하지 않았습니다.
- 파일: `src/app/(dashboard)/records/calculator/page.tsx`, `src/components/records/GradeCharts.tsx`

## 데이터

- 성적과 스펙은 이전처럼 **브라우저 로컬(사용자별)에만** 저장되고 DB에는 동기화하지 않습니다. 키는 기존과 같습니다(`unilink:grade-records`, `unilink:spec-records`). 새로 `unilink:grade-settings`를 추가했습니다.
- `GradeRecord`
  - 추가한 필드: `retake`, `retakeGrade`
  - `grade`에 `NP`를 추가했고, `미정`은 빈 값(`""`)으로 바꿨습니다.
- `SpecRecord`
  - 새 형식으로 바꿨습니다. 종류는 `certificate | language | competition | other`입니다.
  - 추가한 필드: `acquiredAt`, `expiresAt`, `lifetime`, `issuer`, `score`, `award`, `content`
  - 기존 기록은 읽을 때 자동 변환됩니다.
    - `experience` → 기타
    - `memo` → 내용
    - 수상한 경우 `awardRank` → 수상 이력
    - `completedAt` → 취득연월
- 테스트: `tests/record-storage.test.mjs`(평점·재수강·비율·학기 칸·기존 스펙 변환)
