# Claude 스타일 화면 배치 (2026-11-13)

데이터·저장 로직은 바꾸지 않고 화면 구조만 바꿨습니다. DB 마이그레이션이나 서버 함수 변경은 없습니다.

## 1. 왼쪽 목록 (사이드바)

- 이전에는 각 화면 상단의 ☰ 버튼으로 여는 서랍이었습니다. 이제 넓은 화면(1024px 이상)에서는 **기본으로 펼쳐진 고정 목록**입니다.
- 왼쪽 위 목록 버튼으로 접고 펼칩니다.
  - 접으면 본문이 그만큼 넓어지고, 버튼은 본문 왼쪽 위로 옮겨집니다.
  - 상태는 브라우저에 저장됩니다(`unilink:sidebar-open`).
- 좁은 화면에서는 같은 버튼으로 목록을 화면 위에 띄웁니다.
- 구성: UniLink → `새 채팅` → 메뉴(시간표·학습 계획·AI 학습코칭·나의 노트·문제은행·성적 및 스펙) → `고정됨` → `내 수업` → `개인 학습` → 프로필·설정·로그아웃
- 과목·개인 학습은 채팅 목록처럼 보입니다.
  - 마우스를 올리면 고정 버튼이 나오고, 고정하면 `고정됨` 섹션 맨 위로 갑니다(`unilink:sidebar-pins`, 사용자별).
  - 각 섹션 제목을 누르면 접고 펼칩니다.
- 파일: `src/components/layout/Sidebar.tsx`, `SidebarContext.tsx`, `Header.tsx`, `src/app/(dashboard)/layout.tsx`

## 2. 홈(대시보드) = 채팅 화면

- 처음 화면 위쪽에는 Claude 메인처럼 시간대별 인사말과 **채팅 입력창**이 있습니다. 아래쪽에는 오늘 계획·시험·과제·오늘 수업 박스가 한 줄로 있습니다. 입력창 아래의 바로가기 버튼은 없앴습니다.
- **홈은 페이지 스크롤이 없습니다**(1024px 이상).
  - 위쪽(인사말·입력창)과 아래쪽(박스 3개)이 남은 화면 높이를 나눠 쓰고, 박스 내용이 넘치면 박스 안에서만 스크롤됩니다.
  - 대화 화면에서는 메시지 영역만 스크롤되고 입력창은 아래에 고정됩니다.
- **대화를 시작하면 일정 박스가 접힙니다.**
  - 첫 메시지를 보내면 오늘 계획·시험·과제·오늘 수업 박스가 아래로 내려가며(0.3초) 사라지고, 그만큼 대화창이 커집니다.
  - 입력창 아래의 얇고 긴 손잡이(위 화살표)를 누르면 박스가 다시 올라옵니다. 이때 대화(남는 높이, 안에서 스크롤)·입력창·박스(화면의 약 40%)가 한 화면에 함께 보입니다.
  - 펼치거나 접은 뒤에는 대화가 최신 메시지 위치로 맞춰집니다. 같은 손잡이(아래 화살표)로 다시 접습니다.
  - 접힌 박스는 키보드 포커스도 받지 않습니다(`inert`). `새 채팅`을 누르면 처음 화면으로 돌아갑니다.
  - 데모 배너처럼 앱 위에 붙는 요소의 높이는 `--app-top`으로 재서 뺍니다(`SidebarContext.tsx`). 왼쪽 목록 높이도 같은 방식이라, 데모에서도 목록 맨 아래 프로필이 보입니다.
  - 좁은 화면에서는 박스가 세로로 쌓이므로 페이지 스크롤을 유지합니다.
- 입력창
  - 글을 입력하면서 `+` 버튼으로 여러 파일을 첨부할 수 있습니다.
  - **화면 어디에든 파일을 끌어다 놓으면** 첨부됩니다(전체 화면 표시).
  - 첨부 파일은 칩으로 보이고 하나씩 뺄 수 있습니다. Enter는 보내기, Shift+Enter는 줄바꿈입니다.
- 보내면 대화 화면으로 바뀌고 입력창이 아래에 붙습니다.
  - 첨부 파일은 이전 `파일 추가` 박스와 **같은 자동 분류 로직**으로 처리합니다. 결과(종류·과목 수정 가능)는 대화 안에 카드로 보입니다.
  - 채팅 답변 기능은 아직 없어서 글만 보내면 안내 문구가 나옵니다.
- `새 채팅`을 누르면 처음 화면으로 돌아갑니다.
- 이전 하단 `파일 추가` 박스는 입력창으로 대체해 지웠습니다. 분류 로직은 `src/components/home/useFileIntake.ts`로 그대로 옮겼습니다.
- 파일: `src/components/home/{ChatHome,ChatComposer,IntakeResultRow,useFileIntake}.tsx|ts`, `src/app/(dashboard)/dashboard/page.tsx`
