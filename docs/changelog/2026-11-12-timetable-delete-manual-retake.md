# 시간표 삭제·직접 추가 · 학점계산기 학기 추가·재수강 처리 (2026-11-12)

## 1. 시간표 삭제

- 시간표 선택 옆 `+` 오른쪽에 **휴지통 버튼**을 추가했습니다. 지금 선택한 시간표와 그 안의 과목을 모두 삭제합니다(확인창이 뜹니다).
- 현재 학기 시간표는 기본 시간표라 목록에서는 사라지지 않고 과목만 비워집니다. 과목이 없으면 버튼이 비활성화됩니다.
- 삭제 후 현재 학기 시간표로 이동합니다. 과목 삭제는 p0 동기화로 DB에도 반영됩니다.
- 함수: `deleteTimetable` (`src/app/(dashboard)/timetable/page.tsx`)

## 2. 수업 추가 창 문구 정리

- 제목은 `수업 추가`입니다.
- 없앤 문구
  - 개설 현황 설명
  - 검색 결과 개수
  - 원본 강의시간 줄, 대상 학년·수업 방식 줄
  - 시간 미정 안내 박스
  - 미리보기 아래의 기존/선택 개수 설명
  - 빈 선택 안내, 하단 주의 문구
  - `선택한 과목만 추가 · 기존 시간표 유지`
  - 미리보기 시간 미정 목록의 회색 라벨
- 남긴 것: 과목 정보(이수구분·학점·수강번호·교수·학과·과목코드), 시간·강의실, 담을 수 없는 이유(시간 겹침 등)
- 시간 미정 과목은 카드에 `시간 미정·별도 운영` 한 줄만 표시합니다.

## 3. 과목 직접 추가

- 시간표 상단에 **`직접 추가`** 버튼을 추가했습니다. 지금 선택한 시간표(과거 학기 포함)에 과목을 직접 넣습니다.
- 입력 항목은 아래와 같습니다.
  - 과목명
  - 요일·시간: 요일을 고르면 요일별 시작·끝 시간을 입력합니다. 요일을 고르지 않으면 시간 미정 과목이 됩니다.
  - 교수명
  - 이수구분: 전필·전선·전기·교필·교선·일선. `전`으로 시작하면 전공으로 셉니다.
  - 학점
- 같은 시간표의 수업이나 반복 일정과 시간이 겹치면 추가하지 않고 알려줍니다.
- `Course`에 `category?`(이수구분) 필드를 추가했습니다. 수강 목록에는 이수구분이 있으면 그것을 표시합니다.
- 파일: `src/components/timetable/ManualCourseDialog.tsx`

## 4. 성적 및 스펙: 나의 학점을 더 크게

- 화면 비율을 바꿨습니다. 이제 **나의 학점 : 스펙 = 3 : 2**입니다(이전에는 나의 학점 300px 고정).
- 나의 학점에 평점·전공 평점·취득 학점을 큰 글씨 카드 3개로 보여주고, 그 아래에 **학기별 평점 그래프**를 넣었습니다. `학점계산기` 버튼은 카드 오른쪽 위로 옮겼습니다.
- 전공 평점에도 재수강 예상(`재수강 시 x.xx`)을 표시합니다.

## 5. 학점계산기

- **학기 추가**
  - 학기 탭 오른쪽 `+`에서 학년(1~6)과 학기(1학기·여름학기·2학기·겨울학기)를 골라 추가합니다.
  - 탭 순서는 `학년 → 1학기 → 여름학기 → 2학기 → 겨울학기`입니다. 예를 들어 `1학년 여름학기`는 1학년 1학기와 2학기 사이에 들어갑니다.
  - 추가한 학기는 `unilink:grade-settings.extraTerms`에 저장됩니다.
  - 과목이 없는 추가 학기는 학기 제목 옆 `×`로 지울 수 있습니다.
- **같은 과목은 최고 성적만 반영(재수강)**
  - 과목명이 같으면(공백·대소문자 무시, 예: `물리학 1` = `물리학1`) 가장 높은 성적 하나만 평점·취득학점·학점 비율·학기별 평점에 반영합니다. 성적이 같으면 나중 학기를 씁니다.
  - 반영되지 않는 행은 흐리게 표시하고, 마우스를 올리면 이유가 보입니다.
  - 함수: `countedRecords`, `supersededIds` (`src/lib/record-storage.ts`)
- **재수강 예정 자동 해제**
  - 나중 학기에 같은 과목 성적이 입력되면, 앞 학기의 `재수강 예정` 체크와 예상 성적이 자동으로 꺼집니다.
  - 저장할 때와 불러올 때 모두 적용합니다(`clearCompletedRetakes`).
- **재수강 예상 평점이 안 나오던 문제**
  - 원인: `재수강 예정`을 체크해도 예상 성적이 빈 값(`-`)으로 시작했습니다. 예상 성적을 따로 골라야만 `재수강 시` 평점이 계산되어서, 체크만 하면 아무것도 안 나오는 것처럼 보였습니다.
  - 수정: 체크하면 예상 성적이 **A0로 기본 선택**되어 바로 `재수강 시 x.xx / 4.5`가 나옵니다. 필요하면 바꾸면 됩니다.
- 그래프 축은 `2-여름`, `1-겨울`처럼 짧게 표시합니다.
