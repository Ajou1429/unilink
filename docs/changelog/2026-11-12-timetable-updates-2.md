# 시간표 수정 사항 2차 (2026-11-12)

[1차 수정](2026-11-12-timetable-updates.md)에 이어서 시간표 화면을 정리했습니다.

## 1. 시간표(학기) 추가

- 시간표 선택 옆에 `+` 버튼을 추가했습니다. 연도와 학기(1학기·여름학기·2학기·겨울학기)를 골라 새 시간표를 만들 수 있습니다. 이미 있는 학기를 고르면 그 시간표로 이동합니다.
- 선택 목록에는 다음 시간표가 나옵니다.
  - 현재 학기
  - 직접 만든 시간표
  - 과목이 들어 있는 학기
- 이전처럼 올해 4개 학기를 자동으로 모두 보여주지 않습니다.
- 정렬 순서: 연도 → 1학기 → 여름학기 → 2학기 → 겨울학기
- 직접 만든 시간표 목록은 `unilink:timetable-terms`(로컬, 사용자별)에 저장됩니다. 과목이 하나라도 들어가면 과목의 `term`으로도 남습니다.
- **학기 판정 변경:** 1~2월을 `직전 연도 겨울학기`로 판정합니다. 예를 들어 2027년 1월은 `2026년 겨울학기`입니다. 이전에는 `2027년 겨울학기`로 판정해서, 겨울학기가 같은 해 1학기보다 앞에 오는 문제가 있었습니다.
  - 관련 함수: `src/lib/academic-term.ts`의 `getCurrentAcademicTermLabel`
  - 대시보드와 기록 페이지도 이 함수를 같이 씁니다.
- 시간표 삭제 기능은 아직 없습니다.

## 2. 상단 정리

- 시간표 선택 위의 `2026년 2학기 · 총 N학점 · 전공 N학점 · 비전공 N학점` 문구를 없앴습니다.
- 전체/전공/비전공 과목 필터를 없앴습니다. 시간표와 수강 목록은 항상 전체 과목을 보여줍니다.

## 3. 일정 추가 통합 (+ 하루 종일)

- `월간 일정 추가`와 `기타 일정 추가`를 **`일정 추가`** 하나로 합쳤습니다. 다이얼로그는 `src/components/timetable/ScheduleDialog.tsx`에 있습니다.
- **요일 반복**
  - 끄면 날짜 하나짜리 일정입니다. 기존 월간 일정(`MonthlyEvent`)으로 저장됩니다.
  - 켜면 요일을 골라 요일별 시간을 지정합니다. 기존 기타 일정(`WorkSchedule`)으로 저장됩니다.
  - 수정할 때 반복을 켜고 끄면 반대쪽 형식으로 옮겨 저장되고, 원래 항목은 지워집니다.
- **하루 종일**
  - 시간 입력이 사라집니다.
  - 저장값은 `allDay: true`, 시간은 `00:00–23:59`입니다.
  - 주간 시간표에서는 수업이나 다른 일정 위에 덮지 않고, 격자 위의 **`종일` 줄**에 따로 표시합니다.
  - 월간 달력에서는 그날 맨 위에 시간 없이 표시합니다.
  - 수업 추가 시 시간 겹침 검사에서 빠집니다.
  - DB 동기화 때 `is_blocking: false`로 올라갑니다. 코칭이 그날 전체를 막힌 시간으로 보지 않게 하기 위해서입니다.
- 진입 경로
  - 주간 시간표의 빈 칸을 누르면 그 요일과 시간이 채워진 요일 반복 일정으로 열립니다(이전과 같은 동작).
  - 월간 달력의 날짜를 누르면 그 날짜의 일정으로 열립니다.
- 주간 시간표의 반복 일정 블록과 종일 칩을 누르면 바로 수정할 수 있습니다.
- 오른쪽 `기타 일정` 카드는 `반복 일정`으로 이름을 바꿨습니다.
- 시간 입력 컴포넌트를 `src/components/timetable/TimeField.tsx`로 분리했습니다. 과목 수정 폼도 같은 컴포넌트를 씁니다.

## 4. 불필요한 문구 제거

- 시간 미정 과목 목록 오른쪽의 회색 `시간 미정·별도 운영 · N학점` 문구를 없앴습니다.
- 시간표 블록의 기본 문구(`기타 일정`, `월간 일정`)를 없앴습니다. 장소가 있을 때만 장소를 표시합니다.
- 앞으로도 꼭 필요하지 않은 보조 문구는 넣지 않는 방향입니다.
