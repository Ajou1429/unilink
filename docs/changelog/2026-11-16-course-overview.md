# 과목 화면 개편 (2026-11-16)

이제 자료·문제·계획은 홈 채팅으로 넣고 고칩니다. 그래서 과목 화면을 **보기 전용 요약**으로 바꿨습니다.

## 화면 구성

- **맨 위 과목 정보 상자는 그대로**입니다(과목명·학점·교수·강의실·시간·성적 반영비율·노트/계획/파일 수). 오른쪽 위에 **설정 버튼(톱니)**만 추가했습니다.
- 그 아래에 `중간고사` / `기말고사` 탭이 있습니다. 탭 옆 숫자는 그 범위의 항목 수입니다.
- 탭 아래를 3칸으로 나눴습니다. 좁은 화면에서는 세로로 쌓입니다.
  - **강의자료**
    - 나의 노트에서 이 과목에 연결된 자료와, 예전 과목 노트·파일을 보여 줍니다.
    - PDF 등은 `열기`로 바로 봅니다.
    - 수정일·이름·종류 순으로 정렬하고, 오름/내림차순을 고를 수 있습니다(기존 정렬 기능 유지).
  - **문제**
    - 문제은행의 파일별 문항 수와 이해도를 보여 줍니다.
    - 파일을 펼쳐 번호를 누르면 문제 내용(수식·그림)이 보입니다. 이해도는 보기만 합니다.
  - **계획**
    - 직접 만든 계획(과목·주간 학습 계획)과 승인된 AI 코칭 계획을 날짜 순으로 보여 줍니다.
    - 완료한 계획은 줄을 긋습니다.
- 이 화면에서는 고치지 않고 **삭제만** 합니다. 휴지통 버튼은 마우스를 올리면 보이고, 좁은 화면에서는 항상 보입니다. 삭제 전에 무엇이 함께 지워지는지 확인 창을 띄웁니다.
- 예전 탭(과제·시험·일정, 진도·이해도, 강의노트 작성·업로드, 계획 추가, 파일 첨부)은 과목 화면에서 뺐습니다. 데이터와 다른 화면의 기능은 그대로입니다.

## 삭제는 전체 기능에서 지워집니다

| 지우는 것 | 함께 지워지는 것 |
| --- | --- |
| 강의자료(나의 노트) | 노트, 저장된 원본 파일, **그 자료에서 만든 문제은행 문제·이해도·크롭 그림** |
| Drive에서 온 강의자료 | 위와 같음. **Drive 원본은 남기고, 다음 동기화 때 다시 가져오지 않음** |
| 문제 파일 | 문제은행의 그 파일 문항 전체·이해도·크롭 그림 |
| 직접 만든 계획 | 과목 계획·주간 학습 계획·월간 계획·시간표 월간 일정에 복사된 것 모두 |
| AI 코칭 계획 | 계획 항목을 `취소`로 바꿈(실행 기록과 연결될 수 있어 행은 남김). 코칭·대시보드에서 빠짐 |

- 자료와 문제의 연결은 두 가지로 찾습니다.
  1. 대시보드 자동 분류 기록(어느 노트가 어느 문제은행 파일을 만들었는지)
  2. 같은 과목에서 같은 파일 이름

## 설정(과목 상자 오른쪽 위 톱니)

채팅·코칭으로 저장된 기록을 보고 **고치거나 지웁니다**. 고친 내용은 원래 기능의 데이터에 그대로 반영됩니다.

| 탭 | 고칠 수 있는 것 | 반영되는 곳 |
| --- | --- | --- |
| 주제별 이해도 | 학습 상태, 이해도 1~5, 메모 / 삭제 | `record_topic_observation`(새 기록으로 이력 보존, 코칭이 최신 값 사용). 삭제는 주제를 숨김(`archived`) |
| 수업 진도 | 진도 제목, 쪽 범위, 난이도, 빠르기 / 삭제 | 시간표 수업 회차(→ DB 동기화) |
| 문제 이해도 | 문항별 0~5 / 문항 삭제 | 문제은행 |
| 계획 | 제목, 날짜, 완료, 시험 범위 / 삭제 | 위 "삭제" 표와 같은 곳. AI 계획은 날짜를 바꿔도 시작 시각과 길이는 유지 |
| 자료 시험 범위 | 강의자료를 중간 ↔ 기말로 옮기기 | 이 브라우저(아래 참고) |

- 주제별 이해도는 로그인 계정에서만 보입니다(DB 기록).

## 중간고사 / 기말고사 구분

- **문제**: 문제은행에 저장할 때 정한 범위를 그대로 씁니다.
- **강의자료·계획**: 날짜로 자동 분류합니다.
  - 그 과목에 제목에 `중간`이 들어간 시험 일정이 있으면, 그날까지가 중간고사입니다.
  - 없으면 문제은행과 같은 월 기준입니다(3·4·7~10월 중간, 그 외 기말).
- 잘못 들어간 항목은 설정의 `계획` / `자료 시험 범위` 탭에서 옮깁니다. 옮긴 결과는 **이 브라우저에만 저장**됩니다(`unilink:course-period-overrides`). 다른 기기에서는 자동 분류로 보입니다.
