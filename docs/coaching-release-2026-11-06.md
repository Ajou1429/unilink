## 운영 적용

- 대상: `lqwpcwzjbqeunqfliaso`.
- 입력·지침 커밋: `40fb40a`; 모델 분리와 이 문서는 후속 커밋.
- 마이그레이션 0028: 서버 전용 설정에 nullable `synthesis_model` 열 추가. 기존 학습 데이터와 RLS·권한은 변경하지 않음.
- 선택 우선순위: `COACHING_SYNTHESIS_MODEL` > DB `synthesis_model` > 기존 `COACHING_MODEL`.
- 운영 DB: `analysis_model=gpt-5.4-mini`, `research_model=gpt-4.1`, `synthesis_model=gpt-6.1-sol`.
- API 키는 변경하지 않았음. Edge Secrets 수정은 계정 권한으로 거부됐으며, 기존 허용된 DB 관리 및 함수 배포 권한으로 비밀값이 아닌 앱 설정을 추가했음.
- 실제 호출 모델과 실행 이력·비용 집계 모델명이 같도록 연결함.
- Sol: `reasoning.effort=low`, 출력 상한 6,000토큰, 요청 45초. 기존 최대 2회 시도는 유지. 2분 작업 임대를 고려해 시도당 시간 상한을 제한함.
- 일정·휴식·고정 일정 검증, 사용자 승인, 응답 스키마, 요청 중복 방지는 그대로 유지함.

## 확인한 결과

- Node 자동 테스트 121개, Edge 테스트 10개, Edge 타입 검사와 ESLint 통과.
- 입력 개선 시 프런트 TypeScript 및 19개 페이지 전체 빌드 통과. 이번 모델 분리는 UI를 수정하지 않음.
- 실제 운영 API: 개인정보 없는 SQL JOIN PDF 1개, 임시 테스트 계정으로 분석·검색·계획 생성 수행.
- PDF 분석 1단계, 검색 작업 1개, 출처 3개, 같은 상태 재요청 시 분석 작업 추가 0개, 최종 Sol 제안 항목 2개 확인.
- 임시 계정·PDF와 그 소유 데이터는 종료 시 정리했으며 기존 사용자 자료를 모델에 보내지 않음.
- 이 결과는 실제 API 호환성과 흐름 확인이다. 실제 강의 이해 정확도·개인별 시간 추정·학습 효과 개선을 입증하지 않는다.

## 비용 판단

공식 Standard 단가 기준 100만 토큰당 Sol은 입력 $2, 출력 $10, 캐시 입력 $0.10, 캐시 쓰기 $2.50이다. reasoning 토큰은 출력 토큰에 포함되므로 두 번 더하지 않는다. 기존 4.1-mini의 프로젝트 추정 단가보다 입력 약 5배, 출력 약 6.25배 높다. 같은 토큰 수를 가정한 비교이며 실제 요청 비용 배율을 의미하지 않는다.

가령 캐시 없이 입력 10,000토큰과 출력 2,000토큰이면 Sol 텍스트 비용은 약 $0.04이다. PDF 분석·검색·재시도 비용은 별도다. 계산기는 견적이며 실제 청구서를 대체하지 않는다. 현재 제한 범위를 넘는 장문·특수 처리 요금은 별도로 검토해야 한다.

반복 PDF·검색을 DB에서 재사용하고 최종 모델에는 구조화된 근거만 전달한다. 모든 요청을 고강도 추론으로 실행하거나 모든 PDF를 일괄 재분석하지 않는다. 프롬프트 단축의 실제 비용 효과는 운영 usage로 측정한다.

## 다음 평가와 되돌리기

같은 과목 자료에서 이해도·마감·가용시간만 바꾼 사례를 비교한다. 자료 해석, 근거 일치, 작업 구체성, 시간 제약, 비용·지연을 각각 평가한다. 기존/신규 프롬프트는 같은 모델로 먼저 비교하고, 모델 비교는 같은 입력으로 수행해 원인을 분리한다. 실제 수행 데이터를 쌓은 뒤 개인 시간 추정과 추천 보정을 검토한다.

모델 문제가 있으면 DB `synthesis_model`을 `null` 또는 검증된 이전 모델로 바꿔 되돌릴 수 있다. 명시적 `COACHING_SYNTHESIS_MODEL`이 있다면 그것이 우선한다. DB 자료를 삭제하거나 기존 계획을 변경할 필요는 없다. 입력 코드를 되돌리는 경우에는 이전 함수 코드를 배포하고 실행 이력의 프롬프트 버전을 확인한다.
