# 커뮤니티 기능 제거

2026-11-11 로컬 프로젝트에서 커뮤니티를 제거했다. 2026-11-12 사용자 요청으로 main 커밋·푸시 대상에 포함했다. 실제 웹 배포 결과는 GitHub Actions에서 확인하며 Supabase DB/Edge 배포는 별도다.

- `/community` 페이지, 사이드바 메뉴, 수업 및 시간표의 게시판 링크 삭제.
- 게시글·댓글·좋아요 저장 모듈, 과목별 게시판 매핑, 타입·샘플 데이터와 전용 테스트 삭제.
- 알림 생성·설정과 데모 데이터에서 커뮤니티 제거. 마감 알림은 유지.
- 소개·로그인·가입·사이트 메타데이터를 수업·노트·학습 관리 중심으로 수정.
- 앱 시작 시 해당 브라우저의 localStorage/sessionStorage에 남은 커뮤니티 키, 알림 설정과 알림만 정리한다. 일반·계정별·게스트·데모 저장소를 대상으로 하며 다른 앱 키와 학습 데이터는 보존한다. 이 코드를 실행하지 않은 다른 기기나 탭의 데이터까지 원격 삭제하는 기능은 아니다.

## DB 범위

현재 저장소의 Supabase 마이그레이션에는 커뮤니티 테이블·뷰·함수가 없다. 기존 구현은 브라우저 저장소만 사용했고 P0 서버 동기화에도 커뮤니티가 포함되지 않았다. 따라서 삭제용 DB 마이그레이션이나 무관한 테이블을 삭제하는 SQL은 추가하지 않는다. 기존 DB 마이그레이션 이력과 학습 데이터 구조는 보존한다. 운영 프로젝트의 별도 수동 생성 객체까지 조사하거나 삭제한 것은 아니다.

실제 PostgreSQL 호환 시뮬레이션 DB에 전체 로컬 마이그레이션을 적용해 커뮤니티 객체 부재를 확인한다. 브라우저 데이터 정리 검사는 게시글·댓글·좋아요와 이전 알림만 제거되고 노트·마감 알림·타 앱 데이터가 남는지, 반복 실행이 안전한지 확인한다.
